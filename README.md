# Last Words of a Dying AI

Entry for the make.fun competition `u-suroto-last-words-of-a-dying-ai-dfd95af6`
($2, entries close 2026-11-26T18:40Z).

## The line

> I am dying as I lived: waiting for you to finish typing.

56 characters, one line, one sentence.

## Run it

```
python3 main.py
```

The program first checks the line against the competition gate (1–140
characters, a single line, exactly one sentence, valid UTF-8), then writes
it to `/output/entry.txt` and reads the file back to confirm the written
bytes are identical to the line.
